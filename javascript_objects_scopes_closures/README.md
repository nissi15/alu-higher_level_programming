# JavaScript - Objects, Scopes and Closures

This project is all about learning how objects, scopes, and closures work in JavaScript. I practiced creating classes, using inheritance, and writing functions that take advantage of closures.

## What I learned

- How to create a class in JavaScript using the `class` keyword
- How to add methods to a class
- How class inheritance works with `extends` and `super()`
- What closures are and how to use them
- How `this` works inside classes
- How to export and import modules in Node.js

## Files

| File | Description |
|------|-------------|
| `0-rectangle.js` | An empty class that defines a Rectangle |
| `1-rectangle.js` | Rectangle class with a constructor that takes width and height |
| `2-rectangle.js` | Rectangle class that handles invalid width/height values |
| `3-rectangle.js` | Rectangle class with a `print()` method that draws it with X's |
| `4-rectangle.js` | Rectangle class with `print()`, `rotate()`, and `double()` methods |
| `5-square.js` | Square class that inherits from Rectangle |
| `6-square.js` | Square class with a `charPrint(c)` method for custom characters |
| `7-occurrences.js` | Function that counts how many times an element appears in a list |
| `8-esrever.js` | Function that reverses a list without using the built-in reverse |
| `9-logme.js` | Function that tracks and prints the number of times it's been called |
| `10-converter.js` | Function that returns a converter for changing number bases |

## Requirements

- All files run on Ubuntu 20.04 LTS with Node.js 14.x
- Code follows semistandard style
- No use of `var`

## How to run

```bash
node 0-rectangle.js
```

Or make the file executable and run it directly:

```bash
chmod +x 0-rectangle.js
./0-rectangle.js
```
