The ``5-text_indentation`` module
=================================

Using ``text_indentation``
--------------------------

Import the function:

    >>> text_indentation = __import__('5-text_indentation').text_indentation

A new line is added after each of the characters . ? and ::

    >>> text_indentation("Hello. How are you? Fine:")
    Hello.
    <BLANKLINE>
    How are you?
    <BLANKLINE>
    Fine:
    <BLANKLINE>

Spaces around the delimiters are removed:

    >>> text_indentation("   Hello.   World?   ")
    Hello.
    <BLANKLINE>
    World?
    <BLANKLINE>

A text without any delimiter is printed as it is:

    >>> text_indentation("Holberton")
    Holberton

An empty text prints nothing:

    >>> text_indentation("")

A text with only delimiters:

    >>> text_indentation("...")
    .
    <BLANKLINE>
    .
    <BLANKLINE>
    .
    <BLANKLINE>

The text must be a string:

    >>> text_indentation(12)
